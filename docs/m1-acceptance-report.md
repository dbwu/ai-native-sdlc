逐条复核的 15 个知识候选、24 个关系候选和 19 个验收条件均能从本轮原文找到支持依据；112 次引文引用均通过固定来源摘要和码点区间核对。这是三个短文样本的结果，不能推断对其他业务文档的总体准确率。语义核对覆盖以下内容：

| 范围 | 结果 |
|---|---|
| 基础选课 | 有效学生／教学班标识作为前置范围；新增记录并返回标识；同一学生重复提交同一班返回原记录且数量不变。 |
| 容量 | 非负整数、成功后记录数不超过容量、满员拒绝新学生、零容量拒绝新增均保留。满员不影响已有学生重复提交。 |
| 时间冲突 | 同一学期、任意时段对、同一星期几重叠即拒绝；左闭右开、首尾相接和不同星期几不冲突。 |
| 例外与副作用 | 重复提交不与自身冲突；拒绝不改变已有记录或占用额外名额。 |
| 未决规则 | 容量不足与时间冲突同时出现时的错误优先级列在待审阅事项，未擅自确定。 |
| 范围控制 | 账号管理、教学班维护、退课、缴费、候补等没有被生成为本轮已确认功能；未添加数据库或框架要求。 |
