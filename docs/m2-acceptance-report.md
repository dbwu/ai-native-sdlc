## 实际发现的问题与保护效果

容量并发候选只给出一个新的验收条目，原有五条无稳定键的文本验收条件没有按原项保留。模型在警告中建议保留旧条件，但候选本身仍会替换验收条件列表。M2 比较据此显示「验收条件发生修改或移除」，要求人工核对。这不是五个语义事实都消失的断言：其中有并发条件的重述，需要审阅人决定条目对应、保留或修订方式。

两份草案在不填写处理决定时，页面禁止建立提案，直接调用接口也返回 409。检查前后知识内容一致，提案数均为零。没有因模型声称“待审”或警告“保留旧条件”而绕过真实候选比较。

影响路径来自已保存的知识关系及项目基线引用，包含关系版本、正反方向及历史端点版本提示。它只表示需要复核，未宣称代码已经修改、测试已经重新运行，或图中每条消息都发生变化。
